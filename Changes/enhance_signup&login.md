## NEW FEATURE ADDITION: CONTINUE WITH GMAIL (UI ONLY)

### Purpose

Enhance the Login and Sign Up pages by adding a **“Continue with Gmail” option** to simplify user access and align with modern authentication experiences.

This is **UI only**. Do not implement backend functionality.

---

## Placement (VERY IMPORTANT)

* Place the **“Continue with Gmail” button ABOVE the form fields**
* Add a separator between the Gmail button and the form

### Layout Order:

1. Page Title and Subtitle
2. Continue with Gmail button
3. Divider with text "or"
4. Form fields
5. Submit button

---

## Gmail Button Design

### Text:

"Continue with Gmail"

### Style:

* Full width button
* White background
* Thin border (light gray)
* Rounded corners
* Slight shadow

### Content:

* Gmail icon on the left
* Text centered vertically

---

## Icon

* Use Google “G” icon (SVG or image)
* Size: small and aligned with text
* Proper spacing between icon and text

---

## Divider Design

Create a horizontal divider with text:

"or"

### Style:

* Thin lines on both sides
* Text centered
* Light gray color
* Proper spacing above and below

---

## Interaction and Animation

* Button hover:

  * Slight shadow increase
  * Smooth transition
* Subtle click feedback
* Maintain consistency with existing animations

---

## Design Consistency Rules

* Do NOT change:

  * Existing layout
  * Colors of main buttons
  * Typography
  * Spacing system

* Ensure:

  * Gmail button matches overall style
  * No visual clutter
  * Clean integration

---

## UX Guidelines

* Keep the interface simple
* Make Gmail option clearly visible but not overpowering
* Maintain balance between Gmail login and manual form

---

## Responsive Behavior

* Gmail button should remain full width on mobile
* Divider should scale properly
* Maintain spacing on smaller screens

---

## Goal

This feature should:

* Improve user convenience
